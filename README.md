心锚，是给正在经历失去的人准备的一个小小的、只属于你自己的地方。

失去重要的家人或爱人之后，那种情绪往往不是一天就过去的——它会在深夜、在空下来的时刻突然涌上来。心锚想做的，不是教你「怎么好起来」，而是在那个最难熬的瞬间，帮你把涌上来的东西先接住：此刻有多想 TA、有多慌、身体是什么感觉，记下来就好。不评分、不比较、不催你「加油」。

它也会陪你把生活一点点重新捡起来：今天吃了什么、动了没有、做了哪几件小事、遇见了谁、心里又是哪几样感受在起起伏伏。日子久了，你能在自己的记录里，慢慢看清那段时间的真实模样。

而当你真的撑不住、觉得无助的时候，心锚还有一个不打分、不说话的「安全出口」——它不会问你为什么，只是陪你做几件身体上能做的事、换个地方待着、给一个重要的人打个电话，直到你觉得自己能松开一点了。

数据只存在你自己的手机里，不上传、不联网。你只需要，在难受来的那一刻，把它打开。

它是为谁做的
给正在经历失去重要的人的你——丧亲、离别、断联、分手。最难熬的那几个小时常常发生在凌晨，所以心锚把「一天」的边界挪到了早上六点，凌晨三点记下的东西，仍属于「昨天」。

记录，本身就是干预
打开就能把此刻接住：想念、想联系、想确认、恐慌，各拉一条 0–10 的刻度；还有被抛弃感、愤怒、羞耻、恐惧、孤独、不甘六支情绪。可以只记恐慌一条，没填的格子就是空白，不会当成 0 分，也不参与任何平均。

把生活一点点捡回来
「生活」里记下吃饭、身体、今天做了什么、遇见了什么、心里六样感受的起伏。它不考核你，不数连续天数，空白的日子不解释成「什么都没做」——只是如实留下痕迹。

一处安静的安全出口
当你真的撑不住时，app 里藏着一个「安全底座」：不记录任何东西，只带人走三步——先做一件身体上的事（冷水洗脸、呼吸、走动、喝水、吃药）、离开那个让你更难受的位置、给一个重要的人打个电话——然后轻轻问一句「我安全了」。它不预置任何号码，你比我更清楚该找谁。

完全属于你
没有网络权限，所有数据只在手机本地，卸载即删。想留底，可以导出 CSV、存长图，或把今天这一段复制发出去带给咨询师看。
